# 时序日历 · Streamlit 在线版

手机和电脑通过浏览器查看51电子万年历，直接调整设备日期、时间、温湿度提醒范围与临时消音，无需登录。

这是用户确认的公开演示模式：任何拿到网址的人都可以查看和控制此设备。OneNet Token仍只在服务器端使用，不会发送到访客浏览器。

此项目是独立在线版，与本地USB上位机分开运行。2026-10-14湿度报警升级需要同时更新51、ESP8266、本地网页和微信小程序；旧版固件仍可查看，湿度设置会保持禁用直到新鲜阈值上报。

阶段16追加 `TemperatureAlarm` / `HumidityAlarm` 两个只读属性，用51实际判定分别显示温度越限、湿度越限、两项同时越限。消音不清除越限来源；缺项、过期、跨批次或与总报警矛盾时显示“等待分项上报”，不根据读数自行猜测。提醒卡片将温度和湿度排成两行，范围、单位和状态使用相同布局。

## 功能

- DS1302设备时间、月历、DS18B20温度与DHT11湿度。
- 自动每5秒刷新；只显示有效、新鲜的采集状态。云端温度保留一位小数，湿度保持整数。
- 日期时间写入、一键同步北京时间、温湿度上下限修改、临时消音和恢复声音。
- 温度或湿度任意一项越限，由51启动报警。消音约10秒后仍超限会自动再次响起，网页不自行发送恢复声音命令。
- 控制前检查网关在线、51通信与状态新鲜度；收到设备确认并核对新上报的属性后才提示成功。
- 历史趋势位于设置之前：温度/湿度同图、左右独立单位轴，保留无数据网格提示。
- 设置不再折叠：顶部可一键跳到设置区；白色卡片内以日期时间、温度提醒、湿度提醒、蜂鸣器四个分段选项切换。
- 白色、深青与焦糖配色，手机窄屏布局；无外部字体或图片CDN依赖。
- 最近一小时OneNet真实历史曲线。历史记录缺失时不生成模拟曲线。
- 酒精检测与电机状态采用与本地蓝牙端一致的图标、留白和读数层次，标题统一为“拓展功能”。
- MQ-3显示采样电压、相对响应指数、12位ADC原值与本次浏览收到的采样趋势；不将响应指数当作真实浓度或安全等级。
- 电机显示51实际档位、PWM占空比和四档指示，设置区提供停止0%、低档40%、中档50%、高档60%的云端控制。

## 阶段41：电机档位定稿

- 统一51、ESP、蓝牙网页、在线网页与小程序的档位对应值为0% / 40% / 50% / 60%；命令仍为0～3档，不新增协议。
- PWM是设定占空比，不是实测转速。页面仍须收到新鲜且匹配的51实际档位与PWM回报才显示有效，旧版中高档回报会显示为未就绪，不会冒充新档位。
- 配套51固件与阶段40的B方案相同；已烧录B的51不用重复烧录。ESP须烧录新映射，蓝牙网页刷新，在线网页上传更新，小程序重新预览或上传。
- OneNET原模型的MotorPWM范围0～70已包含新值，无需为本次调档重新导入；本地模型只同步描述，保留旧范围兼容。先停止电机，再配套更新，避免混用新旧映射。
- 本次不改变PWM频率、LCD驱动、电机启动方式、EEPROM、确认或超时逻辑，也不代表供电干扰或偶发复位已解决。

## 阶段36：拓展功能界面

本轮修改`app.py`、`ui.py`和`assets/theme.css`，沿用原OneNet通信与命令确认逻辑；无需修改物模型、51或ESP固件，也不影响微信小程序与蓝牙网页。

酒精曲线只记录本次浏览会话收到的有效`AlcoholRaw`，最多120个记录、保留一小时以内的数据。重复读取缓存不补点，缺报20秒或观察到无效/离线状态时断线；重新打开网页不保留这段会话记录。它不是OneNet历史数据库的完整一小时曲线，且没有为此增加云端历史查询。离线时若保留历史片段，会明确标为历史，不当作当前读数。

小图标和曲线使用代码生成、内嵌的静态SVG图片，以兼容Streamlit的HTML过滤；无需外部图片、字体或脚本。无样本不绘制虚构平线，单样本只画一个点。

电机高亮仅取实际档位，不取点选目标。所有下发仍只发送一次，并等待51确认与新的实际状态；未确认不会显示成功，断网不自动停机，云端停止不等同于急停。请勿同时从按键、蓝牙和网页争用调速。

上传GitHub后在线页面才会更新；本地源码或离线示例预览不代表已发布。只需替换上述三个网页文件；若此前阶段32尚未上传，使用配套完整网页包覆盖仓库对应路径。

## 部署到Streamlit Community Cloud

1. 打开 https://share.streamlit.io/ 并登录已关联GitHub的账号。
2. 选择创建应用/Deploy an app，选择该项目仓库。
3. Branch填写 `main`，Main file path填写 `app.py`。
4. 在Advanced settings中选择Python **3.12**。
5. 在Secrets中按 `secrets.example.toml` 的配置名填写真实值；不要提交到GitHub。
6. 确认采用公开演示模式：部署后老师和其他访客都可以直接查看并控制设备。

```toml
ONENET_TOKEN = "设备级Token的完整字符串，不加Bearer"
ONENET_PRODUCT_ID = "你的产品ID"
ONENET_DEVICE_NAME = "你的设备名称"
```

Token使用设备级授权即可，不需要用户级AccessKey。不要把Token放进网页URL、公开仓库、截图或老师分享链接。旧配置中的 `CALENDAR_PASSWORD` 不再读取，无需改动已有Cloud Secrets也能运行。

## 本次OneNet物模型升级

先在原产品修改物模型并保存、生效，再更新51与ESP固件。标识符的大小写必须一致。

| 属性标识符 | 本次修改 | 类型与范围 |
| --- | --- | --- |
| CurrentTemperature | 从整数改为浮点，保留真实25.1而非取整25 | float，-40～125℃，步长0.1，只读 |
| CurrentHumidity | 不改 | int32，0～100%RH，只读 |
| HumidityLow | 新增湿度报警下限 | int32，0～100%RH，步长1，读写 |
| HumidityHigh | 新增湿度报警上限 | int32，0～100%RH，步长1，读写 |
| TemperatureAlarm | 新增温度越限状态 | bool，只读，51实际判断 |
| HumidityAlarm | 新增湿度越限状态 | bool，只读，51实际判断 |

湿度上下限必须一起下发且下限小于上限；温度阈值仍为0～99整数。两组阈值均由51写入EEPROM并读回核对。`AlarmActive`现在表示任一有效温湿度读数越限，`AlarmMuted`表示约10秒的临时消音，不是永久关闭报警。

完整导入文件见 [docs/thing-model.json](docs/thing-model.json)。导入会覆盖原物模型，应先导出原模型，并确认没有遗漏你另外新增的功能点；不要仅导入两个湿度属性。如果平台不允许修改已发布属性的数据类型，请先检查平台提示，不要直接删除旧温度属性及历史记录。

参考：[OneNet物模型数据类型](https://iot.10086.cn/doc/iot_platform/book/api/common/queryThingModel.html)。

## 演示时的说明

- 当前RTC按设备上报值每5秒更新，不假装逐秒实时串流；离线时冻结最后收到的设备时间。
- “同步北京时间”使用云端服务器当前时间转换为UTC+8，**不是读取手机系统时钟**。
- 状态超过20秒、ESP离线或双向通信未就绪时禁用控制；网络异常、超时不自动重发命令，请先刷新核对状态。
- 设置区不参加常规5秒定时重绘；刷新监测不会主动覆盖服务端已保存的编辑草稿。
- 不存在访问密码或登录过期；所有访客拥有相同的控制权限，请不要用作需要私密访问的生产系统。
- 操作记录只保留在当前浏览会话，不是永久审计日志。
- 无人访问12小时后Community Cloud应用可能休眠，需打开网页唤醒；ESP向OneNet上报不受网页休眠影响。
- 手机访问此在线版不需要安装软件。原来USB串口网页继续在本地电脑运行，不能指望Cloud服务器直接读取电脑COM口。

# 酒精检测与电机状态：只读扩展

本轮不加云端调速，保留时间、温湿度、报警来源、阈值和消音控制。

导入并发布更新后的 `thing-model.json`，保留原19项、新增7项只读属性：
`AlcoholRaw`、`AlcoholVoltage`、`AlcoholIndex`、`AlcoholValid`、`MotorLevel`、`MotorPWM`、`MotorValid`。

必须同步更新51和ESP固件，ESP才能收到51原有MQ/FAN帧。单独部署网页不能产生新数据。无新数据时显示等待上报，不将缺失值当成零或“停止”。

独立校验两类回报的有效性、新鲜度与档位/PWM一致性。MQ/FAN不更新DATA心跳、不提供命令发送许可。ESP超时只上传无效标志，不刷新旧测量时间；网页新鲜度上限20秒。

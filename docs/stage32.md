# 云端电机控制

在保留阶段31全部遥测显示的基础上，新增 `MotorTarget`（int32，0～3，rw）。`MotorLevel`、`MotorPWM`和有效性标志仍只读，界面不使用目标回显当作执行证明。

同时更新51、ESP、OneNet物模型、网页和小程序；51复用F0～F3，无新增RAM/引脚，code=8184，最高0x1FFB。四档PWM仍为0/40/55/70%。

每条命令只发送一次。ESP需匹配ACK及其后的新DATA/FAN；网页和小程序需匹配新的实际档位。旧值、平台接收成功或MotorTarget回显均不能假装执行成功。失败/超时不要连续重复提交。

禁止混合控制字段、任意PWM、越界档位。过期/离线/电机回报缺失时禁用控制。原时间/温湿度阈值/消音保留。

请勿与按键或蓝牙同时调速；最后被51接受的命令生效，没有新增强制本地优先权。断网不会自动停机，网络停止不能替代板上停止。LCD电机干扰仍须另行处理。

更新包不含真实Secrets或设备配置。网页源文件更新不等于GitHub/Streamlit已发布，小程序也需在微信开发者工具编译上传。
